# 📚 Estudando Java com DevDojo

Repositório com meus estudos de Java acompanhando a playlist **"Maratonando Java"**, do canal DevDojo. Cada pasta/arquivo corresponde a uma aula da playlist, abordando um tema específico da linguagem.

## 🎯 Objetivo
Praticar e consolidar conceitos de Java conforme avanço nas aulas, mantendo um histórico do meu aprendizado.

## 📂 Estrutura
Cada aula é organizada separadamente, contendo o código desenvolvido durante o estudo do respectivo tema.
